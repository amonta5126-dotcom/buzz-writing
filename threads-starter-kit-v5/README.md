# Threadsスターターキット v5

「毎日のThreads投稿で、フォロワー数に関係なく知らない人へ配られる投稿を作る」ための型一式です。
Claude Code でも Codex でも使えます。Codexには、プラグインとしてそのまま入れられます。

元になった実績（養蜂のアカウントの実測）:
- フォロワー 389人（8/19）→ 1,535人（9/15）→ 1,957人（10/30）
- 8/16〜9/14の30日間の閲覧 240万回。見ている人の99.7%はフォロワー以外
- 最高の1本 いいね10,338
- 1行目に型を入れた投稿は、入れなかった投稿の約2倍のいいね（平均968 対 460）

## 使い方

### Codex の場合（おすすめ：プラグインとして入れる）

`codex-plugin.md` の3つのコマンドを打つか、Codexに「このフォルダをプラグインとして入れて」と頼みます。入れたあとは、どこからでも「今日のThreadsの3本作って」で使えます。

プラグインにしない場合は、このフォルダを開いて「SKILL.mdの手順0から始めて」と一言でも動きます。

### Claude Code の場合

`plugin/skills/threads-starter-kit/` を `~/.claude/skills/` にフォルダごとコピーします。または、このフォルダを開いて「plugin/skills/threads-starter-kit/SKILL.md を読んで、運用を始めたい」と一言。

### 毎日の流れ

1. 初回だけ、AIが5つ質問します（ジャンル・名乗り・書いてはいけないこと・一番買ってほしい商品・コメントの話し方）
2. 毎日「今日の3本作って」。本文・追いリプ4本・画像の指示と、出す前の3つの確かめ結果が出ます
3. 画像を作って、自分の目で確かめて投稿。24時間後の数字を記録シートへ

## 大事な前提

- このキットは「型」と「手順」だけです。**投稿するかどうかの最終判断・公開ボタンを押すのは常にあなた自身**です。
- 実績の数字は元アカウントでの実測です。同じ結果を保証するものではありません。当たりは上位1割に偏ります（91本中の上位10本で、いいねの65%）。
- 9月の末からは、1本あたりの見られる回数が下がりました。当たった型を出し直すと、また伸びた投稿がありました（講義スライド参照）。
- 「死」などの言葉は、コメントで注意を受けたことがあるので避けています。
- 分からないことは、講師へのDMでどうぞ。
