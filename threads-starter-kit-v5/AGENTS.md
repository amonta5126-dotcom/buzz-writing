# このフォルダの使い方（Codex向けの入口）

このフォルダは「Threadsスターターキット v5」です。
作業を始める前に、必ず `plugin/skills/threads-starter-kit/SKILL.md` を読み、そこに書かれた手順・型・禁止事項に従ってください（同じフォルダの他のファイルもそこから読む）。

- `my-config.md` が無ければ、SKILL.md の「手順0」から始める（ユーザーに5つ質問する）
- 「今日の3本作って」と言われたら、SKILL.md の「手順1」に従う
- 画像は `image-kata.md` の型3つに沿って指示を作る
- 投稿・公開はしない。下書きと検品結果を出すところまで
- プラグインとして入れたい場合は `codex-plugin.md` を読む
