# 出す前の合格ライン3つ（3つとも◯で、はじめて出す）

Threadsは「文字を読むアプリ」ではなく「画像を見るアプリ」です（Instagramから生まれた仕組みで、インサイトも表示回数を「再生数」と呼びます）。安定して伸びる形は画像にあり、画像さえ刺されば文章はそこまで高い質でなくても伸びます。逆に、同じ文章でも画像がないと表示が10分の1まで落ちたことがあります。

## 1. 画像は「実写風の、被写体1つのドアップ」か

- 遠景・全景・雰囲気写真・文字入り・イラストは沈む（元アカの実測: 文字だけ12いいね／文字入り図鑑画像29／蜂が写っていない卵の写真72。実写風のドアップ89本の中央値217）
- 横長（4:3）が標準。人の顔は写さない
- 図解を使うなら「1枚を長く見せる」作り（マス目に情報を詰める）に限る

## 2. 1〜2行目だけ読んで「え」と思うか

続きは読まれない前提で書きます。1行目の型別のいいね中央値（元アカ・30日・91本）:

| 1行目の入り方 | 中央値 |
|---|---|
| 問いかけ「〜と思いますか」 | 1,002 |
| 職業に例える「専門の『◯◯』がいます」 | 357 |
| 思い込み暴露「〜だと思っていました」 | 347 |
| 数字から入る | 173 |
| 自分の体験・観察から入る（設定説明） | 121 |

「うちには20群の巣箱があります」のような設定説明から入らない。問いかけ型が一番強いので、意識して増やす。

## 3. その画像は、1行目の主張を証明しているか

被写体が写るだけでは足りません。「羽は治らない」なら擦り切れた羽の逆光、「荷物が多い」なら花粉団子をぶら下げて飛ぶ姿、というように、**1行目で言ったことを1枚で見せる**。花の上の蜂（よくある写真）は31いいね、擦り切れた羽は10,338いいね。文章は同じ作り方でした。

## 3つそろわないときは

2つなら題材を変える。無理に出さない。1日の投稿のうち1本落ちても、翌日に回すほうが伸びます。

## 言葉の注意

- 「死」などの言葉は、コメントで注意を受けた実例があるので避けています。ざわつきは「危険・気持ち悪さ・健気さ」で作る
- 本文に売り込み・リンク・「AI」という言葉を入れない（誘導は追いリプ4本目だけ）
- 効能の断定（治る・効く・予防する）や、実額（売上・価格）は書かない
