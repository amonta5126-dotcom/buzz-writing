# 画像の型3つ（Threadsで止まってもらう1枚）

Threadsは、見る人のほとんどがフォローしていない人です。スクロールしている人は、文字を読む前に画像で止まるかを決めます。元アカ（養蜂）で伸びた画像は、次の3つの型のどれかでした。

## 型1：「え、何それ」の1枚

見ただけで「え、何それ」「なんじゃこりゃ」と思う1枚。

- 伸びた例：擦り切れた羽（10,338いいね）／花粉団子をぶら下げて飛ぶ（6,082）／イモムシを抱えて飛ぶ（5,997）
- 沈んだ例：花の上のハチ、よくある写真（31）／何が写っているか分からない写真（72）
- 決め手：ひと目で「何かおかしい」と分かること。よくある写真は、何の話にでも使えてしまうので止まらない

## 型2：意外性のある1枚をAIで作る

身近なものを、見たことのない近さ・場面で見せる1枚。今はAIで作れます。

- 例：クマムシの顔のドアップ／ラーメンのドアップ／ハチが仲間を運び出す瞬間
- 作り方：「何を」「どこまで近く」「どんな場面で」を1文で決めて、画像AIに出す（下の指示の型）

```
（被写体）の超接写。（意外な場面・動き）。画面いっぱいに1つだけ。
実写の写真のように。自然光。背景はぼかす。文字・ロゴ・人の顔は入れない。横長。
```

例：「働きバチが巣の入口で動かない仲間をくわえて運び出す瞬間の超接写。画面いっぱいに1匹。実写の写真のように…」

## 型3：1行目の話を目で見せる1枚

1行目で言ったことを、画像が1秒で見せる1枚。

- 例：1行目「働きバチの羽は、一度傷んだらもう治りません」→ 画像はボロボロの羽のドアップ
- 1行目「畑には、専門のイモムシ駆除業者がいます」→ 画像はイモムシを抱えて飛ぶハチ
- AIの画像は事実の裏付けにはならない。事実は本文の側で正確に書く

## 3つに共通する決まり

1. **ドアップ**。写すのは1つだけ。SNSは一瞬しか見られないので、散らかった絵より1つをドンと
2. **1行目とセット**。画像だけ、文字だけで考えない
3. **実写（写真のような画像）だけ**。イラスト・図解・文字入りの画像は、元アカでは伸びにくかった（文字だけ12いいね、図解29いいね、実写風217いいね）

## どのAIで作るか

元アカは、2026年8月に同じ指示で5つの画像AIを比べ、一番写真に近かった ChatGPT の画像モデル（GPT Image 2）を使っています。今は定額の Codex から使っています（`codex-plugin.md` 参照）。新しいモデルが出たら、同じ指示で並べて比べ直すのがおすすめです。
