# 追いリプ（自分の投稿への返信）は、伸びた投稿にだけ1本ずつ

同時に4本ぶら下げない。いいねの累計が段階に達した投稿から、次の1本だけ足します。伸びない投稿には足しません。

| 段階 | 目安のいいね | 中身 |
|---|---|---|
| リプ1 | 30 | 補足の事実（本文と重複しない新しい1点）＋**画像1枚** |
| リプ2 | 100 | 別の角度の新事実＋**画像1枚** |
| リプ3 | 150 | 持ち帰り（読者が今日試せる1つ）＋**画像1枚** |
| リプ4 | 200 | 出口。**一番買ってほしい商品**へ案内する。URLを書いてよい唯一のリプ |

- リプ1〜3には毎回画像を付ける。元アカでも、画像の無いリプが続いた投稿を、講義の当日に直したばかりです
- 毎回、新しい事実か画像を1つ足す（順位を上げるためだけの空リプは禁止）
- リプ1〜3にはURLを書かない。本文にも書かない
- リプ4の行き先は1つに絞る。メール登録・スタンプ・商品などを日替わりで回すより、一番買ってほしい商品1つのほうが迷わせない。言い回しだけ日替わりにする（毎日まったく同じ文だと、使い回しに見える）
- 目安の数字は元アカ（1投稿あたりの中央値217）の設定。自分の中央値が50なら「15→50→75→100」のように、自分の中央値に合わせて縮める

# もらったコメントへの返し方

- 相手からコメントが来たら、こちらから返す。**同じ相手とは2往復まで。** 3回、4回と続くと、しつこいと感じる人がいます
- **1〜2文・60字くらい。** 長く説明しない
- **毎回質問で終えなくてよい。** 答えやすい場面だけ、短い問いを1つ。2往復目は問いかけずに締める。会話が終わりそうなら、そこで終える
- 相手を否定しない。「違います」「いや」で始めない。まず受け止めて、事実は足す形で伝える
- 絵文字は文末に1つまで。「うまい」と思わせる一段深い事実か軽い笑いを足す
- 話し方は自分の声が基本（元アカも10/28から、なりきりをやめて自分の声に戻しました）。ジャンルの「本人」（神社なら狛犬、城なら鬼瓦）になりきるのも、キャラとして反応してもらえるので選択肢としてはあり
- 攻撃的・政治的なコメントには返さない。質問には知っている範囲で短く。知らないことは無理に答えない

例:
- コメント「知らなかった！」→「僕も最初に見たとき、目を疑いました😅」
- コメント「うちの畑にもいます」→「同じ子かもしれませんね。見かけたら、ぜひ観察してみてください🐝」

# コメントを呼ぶ3条件（投稿を作る側の話）

1. 答えたくなる問いがある（「泥の壺の中身、想像つきますか」）
2. 思わず言いたくなるざわつき（危険・気持ち悪さ・健気さ。「死」系の言葉は避ける）
3. 自分の体験を話したくなる余白（「うちの畑の葉も丸く切られてた」）

元アカの実測: コメント5件未満の投稿は平均表示1,086、20件以上の投稿は22,111。コメントが付くほど、知らない人へ配られます。
