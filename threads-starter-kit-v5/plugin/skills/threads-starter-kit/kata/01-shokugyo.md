# 型① 職業に例える（「専門の『◯◯』がいます」）

対象（生き物・建物・街）の中の役割や仕組みを、人間の職業に置き換えて真顔で語り、「れっきとした仕事です」で締める型。元アカの実績: イモムシ駆除業者 5,997いいね／マッサージ師 1,135／情報統制係 463／葬儀屋 14,662（8月）。

## 骨組み

```
1行目: 「[場所]には、専門の『[職業名]』がいます。」
2〜4行: その役割が実際に何をしているかを、具体の動作で2〜3文（数字が1つ入ると強い）
最後: 「[目的]のための、れっきとした仕事です。」
```

- 1行目に職業名を出す。対象の名前（蜂・神社）は2行目以降でよい
- 動作は「見える」描写にする（画像がその動作を証明できるように）
- 締めは真顔。オチで笑わせようとしない（真面目にやっていることが少しおかしい、が温度）

## 記入例（元アカ・蜂）

畑には、専門の「イモムシ駆除業者」がいます。
アシナガバチの幼虫は青虫や毛虫しか食べられません。だから親は一日中、畑の葉を回って青虫を探し、肉団子にして巣へ運びます。
農薬を使わない畑が回っているのは、この業者のおかげです。れっきとした仕事です。

画像: アシナガバチが青虫を抱えて飛ぶドアップ（1行目「駆除業者」を証明）

## 記入例（神社仏閣・城）

城の屋根の一番上には、専門の「火消し」がいます。
鯱（しゃちほこ）は、体は魚で頭は虎の想像上の生き物です。口から水を吹いて火を消すと信じられ、火事よけのまじないとして天守のてっぺんに一対で置かれました。
木でできた城を守るための、れっきとした仕事です。

画像: 金の鯱の顔と口元のドアップ（空を背景に）

## 記入例（熊本市の街）

熊本の街には、専門の「水の番人」がいます。
市内の水道水はほぼ全部が地下水で、阿蘇に降った雨が何年もかけて街の下へ届きます。その入口を守っているのが、田んぼです。
蛇口をひねるたびに田んぼが働いている、れっきとした仕事です。

画像: 湧き水が砂を巻き上げて湧く水底のドアップ

## 記入例（AIの使い方）

うちのパソコンには、専門の「議事録係」がいます。
会議の録音を放り込むと、話した順ではなく決まった順に並べ直して、期限つきの宿題だけを抜き出します。
自分が寝ている間に終わっている、れっきとした仕事です。

画像: 録音機と手書きメモが並ぶ机のドアップ（顔なし）

## 注意

- 記入例の事実関係は、投稿前に自分で確認してから使う（例は型を見せるためのもの）
- 事実だけを使う（本当にやっていない仕組みを「実は〜しています」と語らない）
- 職業名は誰でも知っている職業にする（「情報統制係」より「警備員」「引っ越し業者」のほうが強い）
