# 型③ 問いかけて暴露する（「〜と思いますか」）

1行目で読者に問いを投げ、はぐらかしを1つ挟んでから「答えは、◯◯。」と明かし、理屈の一言で締める型。元アカでは1行目の型として最も強く、いいね中央値1,002（他の型の3倍）。コメントも一番付きます（読者が答えを書きに来る）。実績: 泥の壺の中身、想像つきますか 1,002いいね・表示4.4万／巣の中でネズミが死んだらどうすると思いますか 1,866・表示13万。

## 骨組み

```
1行目: 「[光景・状況]、[どうすると／何だと]思いますか。」
2行目: はぐらかし（「[普通の答え]、と思いますよね。」または「私は[普通の答え]だと思っていました。」）
3行目: 「答えは、[意外な正体]。」
4〜5行: それが合理的である理屈を1〜2文
最後: 一言（「理屈だけ見ると、けっこう合理的です。」等）
```

- 問いは「答えを言いたくなる」ものにする（知識クイズより、想像で答えられるもの）
- 答えは一言で言い切る。「答えは、包む。」のように短いほど強い
- 追いリプ1で「答えの続き」を出すと、コメントと合わせて伸びやすい

## 記入例（元アカ・蜂）

泥の壺の中身、想像つきますか。
ドロバチのメスは泥をこねて壺形の巣を作り、毒針で麻酔をかけて動けなくした青虫を、生きたまま詰めていきます。
答えは、子どもの弁当。生まれた幼虫は、新鮮なまま保存された青虫を食べて育ちます。
冷蔵庫のない世界の、保存の仕方です。

画像: 泥の壺に取りついたドロバチのドアップ

## 記入例（神社仏閣・城）

城の門の上に空いた、小さな四角い穴。何のためだと思いますか。
明かり取り、と思いますよね。
答えは、石落とし。門の真下まで来た敵の頭上に、石や熱湯を落とすための穴です。
入口が一番きれいで、一番危ない場所でした。

画像: 門の上の石落としの穴を真下から見上げたドアップ

## 記入例（熊本市の街）

熊本の路面電車、雨の日に線路が光って見える理由、わかりますか。
濡れているから、と思いますよね。
答えは、車輪で磨かれているから。毎日何百回も鉄の車輪が通る面だけが鏡のように削られて、雨をはじきます。
線路の光り方で、その道の混み具合がわかります。

画像: 雨に濡れた線路の光る面のドアップ

## 記入例（AIの使い方）

AIに毎朝仕事を頼んでいる人が、最初にやったこと、何だと思いますか。
プロンプトの勉強、と思いますよね。
答えは、机の上のメモを全部写真に撮ること。AIは知らないことは書けないので、材料を渡すのが先でした。
道具より先に、材料でした。

画像: メモ用紙を撮るスマホの手元のドアップ（顔なし）

## 注意

- 記入例の事実関係は、投稿前に自分で確認してから使う（例は型を見せるためのもの）
- 問いに対する答えが「当たり前」だと沈む（はぐらかしを挟んで、答えを意外に見せる）
- 怖さで引っ張らない。「死」系の言葉は規約上NGになりやすいので使わない
