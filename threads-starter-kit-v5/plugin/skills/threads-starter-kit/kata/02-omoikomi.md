# 型② 思い込みを暴露する（「〜だと思っていました」）

自分（または多くの人）がずっと持っていた思い込みを1行目で言い、正体を明かして、見方が変わる一言で締める型。元アカの実績: 丸い穴は虫食いだと思っていた 5,514いいね／花粉団子は荷物が多いくらいに思っていた 6,082／アーモンドは受粉なんて虫がなんとなく 1,062。

## 骨組み

```
1行目: 「[よくある光景]を、長年ずっと[思い込み]だと思っていました。」
2〜4行: 正体（「正体は、[◯◯]でした。」）と、その仕組みを具体の動作で2〜3文
最後: 見方が変わる一言（「今は[光景]を見るたびに、[新しい見方]。」）
```

- 思い込みは「読者も持っていそうなもの」を選ぶ（自分だけの勘違いだと共感が出ない）
- 「完全に見くびっていました」「舐めていました」のような自分を下げる言い方が効く（読者はいじらない）
- 正体は一言で言えるものにする

## 記入例（元アカ・蜂）

畑の葉っぱにコンパスで描いたような丸い穴が空いていると、長年ずっと虫食いだと思っていました。
正体は、ハキリバチでした。葉を丸く切り取って抱えて飛び、筒の中で一枚一枚を壁材にして、子ども部屋を作ります。
今は丸い穴を見るたびに、どこかで建築が進んでいるんだなと思います。

画像: ハキリバチが丸い葉を抱えて飛ぶドアップ

## 記入例（神社仏閣・城）

神社の狛犬は、左右で同じ顔だと思っていました。
正体は、口を開けた「阿」と閉じた「吽」の一対でした。始まりと終わりを表していて、片方だけ角があったり、子どもを連れていたりします。
今は鳥居をくぐるたびに、先に口元を見ます。

画像: 口を閉じた狛犬の顔のドアップ（苔と彫りの質感）

## 記入例（熊本市の街）

熊本城の石垣の反りは、見た目のためだと思っていました。
正体は「武者返し」で、上へ行くほど急になる曲線は、登ってきた人が最後に反り返って落ちる角度になっています。
今は石垣の前に立つたびに、上を見て首が痛くなります。

画像: 石垣の反りを真下から見上げたドアップ

## 記入例（AIの使い方）

AIに頼むときは、指示を細かく書くほど良いと思っていました。
正体は逆で、うちで一番うまくいったのは「終わりの形」を1行で渡した頼み方でした。途中のやり方は任せたほうが、直しが減ります。
今は頼む前に、完成品の見た目だけを先に決めます。

画像: 付箋1枚だけが貼られたモニターのドアップ（顔なし）

## 注意

- 記入例の事実関係は、投稿前に自分で確認してから使う（例は型を見せるためのもの）
- 「思っていました」は本当に自分が思っていたことか、多くの人が思っていることにする（作り話にしない）
- 正体を明かしたあと、必ず具体の動作を2〜3文入れる（正体だけで終わると薄い）
