# 14日間の試し方

## 日程の目安

- 開始: 9/22（月）〜 できれば9/20までに
- 記録: 毎日、投稿の24時間後に record-sheet.csv へ
- 中間: 10/5頃に1週目の数字を送る（型別の中央値だけでよい）
- 締め: 10/19（日）までの投稿を10/20に集計して送る → 10/30の講義で使う

## 開始前にやること（30分）

1. `my-config.md` を作る（AIに SKILL.md を読ませて質問に答える）
2. 開始前の数字3つを控える（フォロワー数・直近30日のいいね中央値・表示中央値）
3. 直近30日で一番伸びた自分の投稿を1本選び、「画像は何が写っていたか」「1行目は何型か」を書いておく（自分のアカウントの当たりの形）
4. ネタ帳を10個（`neta-bank-template.md`。「オチが一言で言えて、驚きがあるか」で選ぶ）

## 毎日やること（15分）

1. AIに「今日の3本作って」
2. 合格ライン3つを自分の目で確認（gokaku-line.md）。✕があれば題材を変える
3. 画像を作って投稿（時刻は朝2本・夕方1本が目安。慣れたら4〜5本。時刻より画像と1行目の効果が大きい）
4. いいねが段階に達した投稿にだけ追いリプ（oi-reply.md）
5. 前日分を record-sheet.csv に記入

## 変えないこと

- 頻度（1日3本以上）。伸びない日に減らさない
- 画像は毎回。文字だけの投稿を混ぜない（混ぜると比較が壊れる）
- 記録の時刻（24時間後）

## 止める条件

- 規約の警告が出た（「死」系の言葉・攻撃的な表現を使っていないか見直してから再開）
- 2週間、全投稿が開始前の中央値を下回る（型ではなく題材の選び方を疑う。ネタ帳を作り直す）

## 10/30に持ち寄るもの

- record-sheet.csv（14日分・約40行）
- 開始前と14日後のフォロワー数・いいね中央値・表示中央値
- 一番伸びた1本と一番沈んだ1本（画像つき）
- 「自分のジャンルでは元アカと何が違ったか」を1〜3行
