# 記録シート（record-sheet.csv）の書き方

10/30の講義で「実際にやってみてどうだったか」を数字で見せるための記録です。1本の投稿につき1行。**投稿から24時間後**に書きます（同じ時間で揃えるのが大事。1時間後と3日後を混ぜると比べられません）。

| 列 | 書くこと | 例 |
|---|---|---|
| date | 投稿日 | 2026-09-20 |
| slot | 枠 | 朝1／朝2／夕方 |
| kata | 型 | 職業／思い込み／問いかけ／その他 |
| first_line | 1行目（先頭30字） | 泥の壺の中身、想像つきますか |
| image_subject | 画像の被写体（何のドアップか） | ドロバチと泥の壺 |
| image_proves | 画像が1行目を証明しているか | ◯／△／✕ |
| likes_24h | 24時間後のいいね | 312 |
| views_24h | 24時間後の表示（再生数） | 4,100 |
| comments_24h | 24時間後のコメント | 18 |
| reply_stage | 追いリプを何本まで打ったか | 2 |
| note | 気づき（1行） | 問いに答えるコメントが多い |

## 開始前に控える3つ（experiment-plan.md）

- フォロワー数
- 直近30日の「ふつうの投稿」のいいね中央値（上位10本を除いた真ん中の値。Threadsのインサイト→投稿一覧から拾う）
- 直近30日の表示の中央値

この3つがあると、14日後に「底が上がったか」「当たりが出たか」を分けて言えます。

## 見方（週1回）

- 型別のいいね中央値（問いかけが強いか、自分のジャンルでは違うか）
- image_proves が◯の投稿と✕の投稿で、いいねがどれだけ違うか
- コメント20件以上の投稿の表示は、5件未満の投稿の何倍か

元アカの結果（30日）: 問いかけ1,002／職業357／思い込み347、◯の上位4本は5,000超・✕の3本は31〜72、コメント20件以上は表示20倍。自分のジャンルで同じ形が出るかを見ます。
