# Metaの公式の窓口（API）で直接投稿する

元アカは今、Threads・Instagram・Facebookページへ、Metaの公式の窓口（API）から直接投稿しています。**始めたばかりの人は、まず Buffer（`buffer-setup.md`）か手で投稿するので十分です。** これは「慣れて本数が増えたら」の話です。

## 仕組み（3段）

1. **Meta for Developers**（Metaの開発者向けページ）で、アプリを1つ作る
2. そのアプリに Threads・Instagram・Facebookページをつなぐ。つなぐと「投稿していいよ」という許可の鍵がもらえる
3. 鍵を自分のパソコンに保存し、AIが書いたプログラムが決めた時刻に投稿する。コメントへの返信・数字の取得も同じ窓口でできる

## お金

- MetaのAPIは、使った回数で料金はかからない（上限はある。Threadsは24時間に投稿250件・返信1,000件まで）
- 文章やプログラムを作るAIは、Claude Code などの定額プランの中で動かせる
- 参考: XのAPIは前払いで、使った分だけ減る方式（元アカでは10月の30日で約15ドル。残高が0になると止まる）

## 気をつけること

- 鍵は約60日で切れる。切れる前に新しくする仕組みが要る（元アカは毎週自動で更新）
- 鍵は他人に見せない。チャット・資料・投稿に貼らない。保存する場所だけ決めて、そこから読む
- 設定は人によって違うので、このキットにはスクリプトを入れていません。つなぎ方の相談は講師へのDMでどうぞ
