# Buffer（予約投稿サービス）の始め方

> v5の補足: 元アカは今、Metaの公式の窓口から直接投稿しています（`meta-api-memo.md`）。始めるときは、手で投稿するか、このBufferが手軽です。

Bufferは、SNSの投稿を「予約」しておいて、指定した時刻に自動で投稿してくれる無料〜有料のサービスです。毎朝手作業でThreadsを開いて投稿する代わりに、前もって3本まとめて予約できます。

ここでは無料プランでの始め方を、エンジニアでなくても迷わないように説明します。所要時間の目安は15〜20分です。

## 全体の流れ

1. Bufferのアカウントを作る
2. ThreadsアカウントをBufferに接続する
3. アクセストークン（このキットのスクリプトが使う「合鍵」）を取得する
4. 取得したトークンを設定ファイルに保存する
5. テスト投稿で動作を確認する

## ステップ1: Bufferのアカウントを作る

1. ブラウザで `https://buffer.com` を開く。
2. 右上の「Get Started」または「Sign up free」ボタンを押す。
3. メールアドレスまたはGoogleアカウントで登録する。
4. 案内に従ってプラン選択の画面が出たら、無料プラン（Free）を選ぶ（あとから有料プランに変更もできます）。

（スクショ挿入位置: この時点でBufferのトップページ・登録フォームのスクリーンショットを貼ると分かりやすいです）

## ステップ2: ThreadsアカウントをBufferに接続する

1. Bufferのダッシュボード（ログイン後の画面）で「Connect a channel」または「+ Add Channel」ボタンを探して押す。
2. 接続先の一覧から「Threads」を選ぶ。
3. Threadsアプリでログインしている自分のアカウントで認証する（Instagramと連携しているアカウントの場合、Instagramログインを求められることがあります）。
4. 接続が完了すると、Bufferのダッシュボードに自分のThreadsアカウントが表示されます。

（スクショ挿入位置: 「+ Add Channel」ボタンの位置、Threads選択画面、認証完了後の画面の3枚を貼ると親切です）

## ステップ3: アクセストークン（合鍵）を取得する

このキットの `scripts/post-to-buffer.mjs` がBufferへ投稿するには、「アクセストークン」という文字列（合鍵のようなもの）が必要です。

1. `https://buffer.com/developers/api` を開く（Buffer Developers ページ）。
2. 「Create an app」または「Manage your apps」から、自分専用のアプリを1つ作る。
3. アプリの管理画面に「Access Token」という項目が表示されるので、その文字列をコピーする。

**この文字列は絶対に他人に見せたり、SNS・チャット・公開リポジトリに貼ったりしないでください。** 家の鍵と同じ扱いです。

（スクショ挿入位置: Developers ページ・アプリ作成画面・Access Token表示箇所の3枚）

## ステップ4: 取得したトークンを設定ファイルに保存する

1. パソコンの「ターミナル」（Macなら`アプリケーション > ユーティリティ > ターミナル`）を開く。
2. 次のコマンドを1行ずつ実行する（`あなたのトークンをここに貼る` の部分だけ、ステップ3でコピーした文字列に書き換える）。

```bash
mkdir -p ~/.config/threads-starter-kit
echo "BUFFER_ACCESS_TOKEN=あなたのトークンをここに貼る" > ~/.config/threads-starter-kit/.env
```

3. これで、トークンはあなたのパソコンの中だけに保存されます（インターネット上には送信されません）。

## ステップ5: ProfileID（投稿先チャネル）を確認する

BufferのAPIは「どのチャネルに投稿するか」を`profile_id`という番号で指定します。ダッシュボードで接続したThreadsチャネルのURLや管理画面のリンクの中に含まれる英数字の並び（例: `5f8a1b2c3d4e5f6a7b8c9d0e`）がそれです。分からない場合は、Buffer developersページの「Profiles」一覧APIを一度呼び出すと確認できます（`scripts/post-to-buffer.mjs`のコメントに手順を記載しています）。

確認できたら、ステップ4の`.env`ファイルにもう1行追加してください。

```bash
echo "BUFFER_THREADS_PROFILE_ID=あなたのProfileIDをここに貼る" >> ~/.config/threads-starter-kit/.env
```

## ステップ6: テスト投稿で動作を確認する

`scripts/post-to-buffer.mjs`の使い方は、そのファイル冒頭のコメントに書いてあります。まずは「予約だけして実際には送らない」テストモード（`--dry-run`）で動作確認してから、本番で使い始めてください。

## うまくいかないとき

- 「Unauthorized」というエラーが出る → トークンの貼り間違い、または期限切れの可能性があります。ステップ3をやり直してください。
- Threadsが接続候補に出てこない → BufferのプランによってはThreads接続に制限がある場合があります。Buffer側のヘルプセンターで最新のプラン条件を確認してください。
- 予約は成功するが投稿されない → Buffer側の管理画面で、その投稿のステータス（Scheduled/Sent/Error）を確認してください。
