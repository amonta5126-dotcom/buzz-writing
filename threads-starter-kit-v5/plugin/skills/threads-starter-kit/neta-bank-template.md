# 自分のジャンル用「ネタ帳」の作り方

投稿する題材（ネタ）を毎回その場で考えると、だんだんネタ切れして質が落ちます。事前に「意外性のあるネタ」をまとめてストックしておく「ネタ帳」を作ると、毎日の投稿作成が速く・安定します。

これは元アカウントで実際に使っている `threads-neta-bank.json` というファイルの構造を、そのまま使える雛形にしたものです。中身（蜂の話）は入っていません。あなたのジャンルで自分のネタ帳を作ってください。

## 作り方

1. 自分のジャンルで「多くの人が知らない・意外だと感じる事実」を思いつく限り書き出す（10〜20個が目安）。
2. 1個ずつ、下のテンプレートの形式で1項目にする。
3. 事実は必ず裏取りする（自分の実体験・実測なら「体感では」と明記、外部の情報を使うなら出典URLを控える）。
4. `my-config.md`の「使用済み題材ログ」と突き合わせながら、使ったものから`usedStatus`を更新していく。

## テンプレート（1項目あたり）

```markdown
### ネタ[番号]: [タイトル・一言で]

**意外性**: [なぜ意外なのか・驚きのポイントを1〜2文で]

**画像アイデア**: [どんな構図で撮る/生成するか。ドアップ・比較構図など]

**向いている型**: [kata/フォルダのどれに乗せるか。例: 03-kansatsu（観察型）]

**使用状況**: 未使用

**出典・裏取り**: [URLまたは「自分の実測（〇年〇月時点）」]
```

## 記入例（ジャンル: 観葉植物）

```markdown
### ネタ1: 葉が黄色くなるのは水のあげすぎが多い

**意外性**: 「元気がない=水不足」と思われがちだが、実際は水のあげすぎ（根腐れ）が原因になっているケースが多い。

**画像アイデア**: 黄色くなった葉のドアップと、健康な緑の葉を並べた対比構図。

**向いている型**: 06-keikoku-taisaku（警告・対策型）

**使用状況**: 未使用

**出典・裏取り**: 園芸系情報サイト〇〇（URL控える）。自分の実測は2026年〇月の失敗経験。
```

## 記入例（ジャンル: AI活用）

```markdown
### ネタ2: 同じ質問でもAIの答えは毎回微妙に変わる

**意外性**: 「AIは常に同じ答えを返す」と思われがちだが、実際は毎回わずかにランダム性を含んでいる。

**画像アイデア**: 特になし（テキストのみで成立する投稿。画像はスクリーンショット的な構図か、AI・脳をイメージした抽象的なドアップで代替）。

**向いている型**: 03-kansatsu（観察型）

**使用状況**: 未使用

**出典・裏取り**: 自分の実測（同じ質問を10回投げて比較・2026年〇月）
```

## 運用のコツ

- **ネタは「意外性」があるかどうかだけで選ぶ。** ジャンルの専門知識がなくても「へえ」と思えるかどうかが基準。
- ネタが尽きたら、同じネタでも別の型（`kata/`フォルダの別ファイル）に乗せて書き直すと、新しい投稿として成立することがあります（切り口を変える）。
- 定期的に（週1回程度）10個くらい新しいネタを書き足しておくと、毎日の作成が止まりません。
