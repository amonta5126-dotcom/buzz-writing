# ネタストック（X版・試作版）

X（旧Twitter）の「オリジナルコンテンツ報酬」を目指す人のための、体験談ネタ帳です。
ブラウザで `index.html` を開くだけで使えます。インストールやログインはいりません。

## できること

- **書くテーマ（必須）** と **自分だけの体験・気づき（必須）** をセットでためます。オリジナルな投稿にするためです
- 投稿文の下書きを書けます。Xと同じ数え方（日本語は1文字=2）で文字数を数えて、「さらに表示」で折りたたまれる位置を表示します
- 状態（アイデア → 下書き → 投稿済み）で管理できます
- **毎日投稿**：何日連続で投稿できているかと、直近14日の投稿状況を表示します
- **報酬への進み具合**：ブルーバッジのフォロワー数（条件：500人）と、90日間のブルーバッジからのホーム表示回数（目安：50万回）を入力すると、条件までの残りを表示します
- 投稿済みのネタに表示回数を記録すると、よく見られた順に並びます
- **仲間・オフ会・相談** のメモを残せます。「ネタにする」で、その体験から投稿ネタを作れます
- バックアップをコピーしておき、あとで貼り付けて復元できます

## 注意（試作版の制限）

- ネタは使っている人のブラウザの中だけに保存されます。別の端末では見えないので、ときどきバックアップをとってください
- 報酬の条件は報道をもとにした目安です。正確な条件と自分の状況は、Xのクリエイタースタジオで確認してください
- ログインと支払いの機能はまだありません
